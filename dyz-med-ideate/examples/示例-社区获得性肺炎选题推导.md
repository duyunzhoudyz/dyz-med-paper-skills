# 示例：从模糊临床观察到结构化研究问题

## 输入（用户原始描述）

> "我是呼吸科住院医师，感觉最近老年社区获得性肺炎（CAP）患者里，有些人恢复得特别慢，好像跟入院时的
> 白蛋白水平有关系，但我不确定这个有没有人研究过，也不知道能不能做成一篇论文。"

## Phase 1：识别起点场景

判定为 **S1（临床观察型）**——从临床现象出发，尚无结构化问题。

## Phase 2：结构化为 PECO（观察性/病因学问题）

| 要素 | 内容 |
|------|------|
| P 人群 | ≥65岁、因CAP住院的患者 |
| E 暴露 | 入院48小时内血清白蛋白水平（低白蛋白 vs 正常） |
| C 对照 | 白蛋白正常组 |
| O 结局 | 住院时长、30天临床恢复达标时间（虚构定义：体温/氧合/CRP复合标准） |

**初步研究问题**：在≥65岁CAP住院患者中，入院低白蛋白血症是否与更长的临床恢复时间相关？

## Phase 3：FINER 检查

| 标准 | 评估 | 说明 |
|------|------|------|
| F 可行 | 中 | 单中心病历回顾可行，需确认白蛋白检测是否为入院常规项目 |
| I 有趣 | 中高 | 老年CAP预后因素是热点，但白蛋白本身不算全新变量 |
| N 新颖 | 低-中（待文献缺口分析确认） | 需要查是否已有类似研究 |
| E 伦理 | 高 | 回顾性病历研究，风险低 |
| R 相关 | 中高 | 若成立，可能提示营养状态筛查的临床价值 |

标注：N（新颖性）评估依赖下一步文献缺口分析，暂定"待确认"。

## Phase 4：文献缺口分析（虚构PubMed检索记录）

- 检索日期：2026-06-01（虚构）
- 数据库：PubMed
- 检索式（虚构）：`("community-acquired pneumonia"[MeSH] AND "albumin"[tiab] AND "aged"[MeSH]) AND ("2019/01/01"[dp] : "2026/06/01"[dp])`
- 命中数：虚构为 14 篇
- 关键文献（虚构 PMID，仅作格式示例）：
  - PMID 00000001（虚构）——报告白蛋白与CAP住院死亡率相关，未涉及"恢复时间"这一结局
  - PMID 00000002（虚构）——纳入人群为全年龄段，未单独分析老年亚组
- 缺口判断：**PARTIALLY FILLED**——白蛋白与死亡率的关联已有研究，但"白蛋白与老年CAP患者临床恢复时间"
  这一具体结局+亚组组合未见直接证据。

## Phase 3.5：机制层级标注

- 当前层级：**association**（相关性层面，尚无机制阐释）
- 建议：如果希望进一步升级为mechanism层级，可转 `/dyz-med-mechanism` 探讨"低白蛋白→炎症反应/免疫功能→
  恢复延迟"这一链条是否有据可查；如果只做描述性/预后关联研究，当前association层级本身也可以是合理
  的研究定位，需在讨论部分明确不做机制宣称。

## Phase 6：输出——研究方向建议（虚构示例）

```
## 研究选题建议

### 推荐方向 1: 入院低白蛋白血症与老年CAP患者临床恢复时间的关联性研究
- 临床缺口: 白蛋白与CAP死亡率关联已有报道，但与"老年亚组的恢复时间"这一结局的直接证据不足（虚构）
- 文献支持: PMID 00000001、00000002（虚构，仅作格式演示）
- 建议设计: 回顾性队列研究（STROBE规范）
- 可行性: 中 — 需确认本单位白蛋白检测覆盖率和恢复时间结局的可提取性
- 发表潜力: 期刊梯队建议 Tier 3（区域/专科期刊为主）

### 风险提示
- 回顾性设计限制因果推断，讨论部分需明确为关联性研究
- 恢复时间的操作性定义需要在方法部分预先明确，避免结局定义漂移
```

> 机制支撑 → `/dyz-med-mechanism`。"
