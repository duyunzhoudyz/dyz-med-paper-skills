# 选题结构化工作表（PICO / PECO / PICOS + FINER）

> 用途：把一个模糊的研究想法，逐步填写成一个结构化、可评估可行性的研究问题。不需要一次性填满，
> 可以先填能确定的部分，其余留空，逐步和用户对话中补充。

## 第一步：确定问题类型

- [ ] 干预性问题（有主动施加的干预，如药物/手术/护理措施）→ 使用 **PICO**
- [ ] 观察性/病因学问题（暴露非人为施加）→ 使用 **PECO**
- [ ] 需要明确研究设计类型 → 使用 **PICOS**
- [ ] 诊断准确性问题 → 使用 **PIRO**
- [ ] 质性研究问题 → 使用 **PEO / SPIDER**
- [ ] 范围综述问题 → 使用 **PCC**（Population-Concept-Context）

## 第二步：结构化要素

| 要素 | 填写内容 | 备注 |
|------|---------|------|
| **P** 人群/患者 | | 疾病、分期、场所、年龄段、纳排标准雏形 |
| **I/E** 干预/暴露 | | 具体措施、剂量、持续时间、测量方式 |
| **C** 对照 | | 安慰剂、常规治疗、无暴露组 |
| **O** 结局 | | 主要结局、次要结局、测量时间点 |
| **S**（仅PICOS）设计类型 | | RCT/队列/病例对照/横断面等 |

**初步研究问题（一句话）：**

> 在____（P）中，____（I/E）相比____（C），是否会影响____（O）？

## 第三步：FINER 可行性检查

| 标准 | 检查问题 | 评估（高/中/低）| 说明 |
|------|---------|----------------|------|
| **F** 可行性 Feasible | 样本量、技术条件、时间/经费是否足够？ | | |
| **I** 趣味性 Interesting | 同行/临床是否关心这个问题？ | | |
| **N** 新颖性 Novel | 是否验证/推翻/延伸已有发现？是否新人群/新方法？ | | |
| **E** 伦理可行 Ethical | 是否能通过伦理审查？知情同意是否可行？ | | |
| **R** 相关性 Relevant | 是否推进临床实践/政策/后续研究？ | | |
