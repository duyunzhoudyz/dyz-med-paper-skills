# 研究注册规范与官方入口

核对日期：2026-07-31

## 主要来源

- **WHO Trial Registration Data Set 1.3.1**：当前页面列出 24 个最小注册数据项。  
  https://www.who.int/tools/clinical-trials-registry-platform/network/who-data-set

- **ICMJE 临床试验注册政策**：建议临床试验在首位参与者同意入组时或之前，在可接受的公共注册库完成注册；对非试验研究鼓励注册，但不机械套用为同等强制要求。  
  https://www.icmje.org/recommendations/browse/publishing-and-editorial-issues/clinical-trial-registration.html

- **ClinicalTrials.gov API v2**：单项研究记录使用 `/api/v2/studies/{nctId}`；字段结构和 API 版本应以当前官方文档为准。  
  https://clinicaltrials.gov/data-api/about-api/api-migration

- **CONSORT 2025**：当前随机试验结果报告规范，已取代 CONSORT 2010；注册、方案和开放科学信息按当前条目及目标期刊要求报告。  
  https://www.bmj.com/content/389/bmj-2024-081123

- **WHO ICTRP Search Portal**：用于发现 WHO 数据提供方中的注册记录；ChiCTR 是可检索的中国来源之一。  
  https://www.who.int/tools/clinical-trials-registry-platform/the-ictrp-search-portal

- **OSF**：可用于适当研究类型的预注册核查。是否需要预注册及如何解释缺失，应结合研究设计、方案和目标期刊，不生成一刀切结论。

## 使用边界

- FDAAA、欧盟或其他监管义务取决于研究类型、地点、时间和适用法律。本技能只记录可能相关的要求并指向当前官方来源，不提供法律结论。
- 注册记录会更新。报告中同时保存首次注册相关日期、最近更新时间和本次检索日期。
- 伦理审批不能替代前瞻性试验注册，注册也不能替代伦理审批。
