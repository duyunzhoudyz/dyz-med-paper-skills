# 期刊评价与投稿伦理资源

- **期刊/出版商官方 Aims & Scope 与 Instructions for Authors**：文章类型、格式、费用和政策的首选来源。
- **PubMed/NLM Catalog 等权威索引**：核对期刊身份、主题和近期内容；收录状态需记录核对日期。
- **DOAJ**：核对开放获取期刊透明度与基本信息的一个来源，未收录不等于期刊不正规。
- **OASPA**：出版商会员信息可作为透明度证据之一，不能单独替代完整核查。
- **COPE**：出版伦理、期刊透明度和可疑投稿行为的参考。
- **Think. Check. Submit.**：作者核查可信期刊和出版商的实用清单。
- **JCR 或机构授权指标数据库**：若用户确需影响因子等指标，应使用当前授权来源；不要凭公开搜索片段或
  模型记忆填值。

一稿多投、作者身份和稿件诚信应遵循目标期刊政策及 ICMJE/COPE 的通行原则。任何接受率、决策时间、APC
和指标都可能变化，输出时必须附来源与日期，未公开就写“未公开”。
