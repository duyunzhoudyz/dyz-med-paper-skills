使用 `dyz-med-translate` 处理中文到英文、英文到中文或双语版本。需要重构论证时先修改内容；翻译阶段依据已确认原稿，不补写原文缺失的研究事实。

## 准备原文与约束

提供完整待译段落、已有术语表、目标语言和用途。尽可能保留章节标题、引用标记、图表编号、统计单位及注册信息。摘要另提供期刊当前格式要求。

> 将这些结果段落翻译为英文，保留数字、单位、P 值、置信区间、引用标记和结论强度。统一术语。原文疑点请在稿外列出，不在译文里替我修造事实。

## 先确认术语，再核对受保护内容

记录关键术语、缩写、疾病名称和结局名称，检查同一概念在全文中是否一致。翻译后逐项对照数字与引用，不把语言自然化等同于内容准确性。

| 内容 | 核对重点 |
|---|---|
| 数字与统计量 | 是否新增、丢失或更换数值和单位 |
| 引用与编号 | 标记与原稿是否对应 |
| 结论表述 | 是否把可能性改为确定性或关联改为因果 |
| 术语 | 同一结局、变量和人群是否采用一致名称 |

本地保护检查可发现部分增删差异，但不能可靠识别两组数字互换、语义漂移或结论强度变化，仍需人工对照。

## 交付哪些文件

保留原文、译文、术语表、检查报告和稿外疑问。需要进一步润色时，再使用 `deai` 改善模板化或重复语言，继续保留事实、证据和必要披露。
