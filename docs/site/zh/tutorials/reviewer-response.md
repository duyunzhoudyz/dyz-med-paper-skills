使用 `dyz-med-revision` 修订现有稿件、准备逐条回复或适配新期刊。收到拒稿信但不清楚根本问题时，可以先让 `manuscript-diagnose` 做只读诊断。

## 准备材料

提供当前稿件、编辑信、按审稿人区分的完整意见、目标期刊要求和已完成的修改。保留稿件版本及页码或行号，便于回复定位。

> 请把审稿意见逐条编号，先形成修订计划。区分可以直接修改的文字、需要澄清的研究事实和需要重新分析的内容。起草回复时只描述实际已完成的改动。

## 建立回复矩阵

| 字段 | 内容 |
|---|---|
| 意见编号与原文 | 保持与编辑信一一对应 |
| 问题与处理方式 | 解释、补充文字、重新分析或有依据地说明不采纳 |
| 正文修改 | 具体修改内容及稿件位置 |
| 回复草稿 | 回应问题、解释依据和指向修改 |
| 状态 | 已完成、待确认、待执行及原因 |

不要把“将补做分析”写成“已完成分析”。涉及新数据、重新分析、伦理、作者信息或其他源事实时，先获得所需确认，再记录实际执行结果。

## 写出有定位的回复

回复应直接回应问题，说明具体改动和位置。不同意某项要求时，提供与研究设计和证据相关的理由，并考虑正文是否需要补充解释。避免整封信只有礼貌套话。

> 根据已完成的正文修改，更新逐条回复。每条注明修改位置；没完成的地方保留待办。核对回复承诺与正文是否一致，再给出本轮修回仍缺什么。

## 最后核对与交付

交付修订稿、回复信、修改记录和待办清单。再检查摘要、结果、讨论和图表的一致性。`submit` 可以整理本地投稿材料；外部上传或正式提交需明确授权与最终确认。
