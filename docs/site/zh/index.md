## 中文沟通，中英写作

这套技能围绕中国医生和医学研究生的科研日常设计：从科室病例与毕业课题出发，考虑现有数据、随访条件、导师意见、学校要求、目标期刊和版面费预算。研究思路可以先用中文讲清，再按用途整理成中英文稿件。

你不必记住技能名。比如：

> 这是我的结果表、已核实文献和讨论初稿。请先梳理主要发现，再重写讨论，区分证据、合理解释和局限。缺依据的地方单列，并用中文说明修改理由。

已有初稿就从诊断和修订开始；收到审稿意见就进入修回。整篇论文不会在一次调用后自动完成。

## 文件可以带走，过程可以继续

技能以 `SKILL.md`、模板、参考资料和本地 Python 脚本组织。论文材料存放在独立项目文件夹；写作提纲、章节、文献记录和修改清单可以继续交给导师与合作者审阅。内置导出器支持基础 Word 审阅稿。

## 先看清适用范围

当前为公开测试版。在线检索依赖数据库权限；内置在线脚本仅覆盖 PubMed。统计执行需要相应环境与具体分析计划的批准。真实宿主调用、连续写作和医学质量尚未全部完成独立验收。教学示例均为合成材料，不能作为发表或使用效果证明。
