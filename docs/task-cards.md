# 常见任务与交付

| 你现在的材料 | 可以直接说 | 最小输入 | 主要交付 |
|---|---|---|---|
| 研究方向不清 | 帮我找可行研究问题 | 临床问题、可用材料与限制 | 待核实问题与可行性路线 |
| 有数据 | 先判断数据够不够，不运行统计 | 数据字典、设计与授权数据 | 充分性与缺口 |
| 有初稿 | 先诊断最需要改什么 | 稿件和目标用途 | 定位明确的问题与下一步 |
| 只翻译 | 翻成英文，数字、引用和强度别改 | 原文、已有术语表 | 译文、保护检查、稿外提示 |
| 有文献库 | 导入RIS/BibTeX并保留来源 | 获准导出文件 | library.json与核验批次 |
| 准备修回 | 按这份审稿意见逐条回复 | 稿件版本、意见、已完成的改动 | 回复表与可核实定位 |
| 导出稿件 | 生成可审阅Word稿 | 章节、图表、引用和格式用途 | 标记明确的DOCX与报告 |

完整授权任务中可连续完成必要的辅助步骤，保留已给的授权，不反复问技能名；未获批准的统计方案变更和外部提交仍单独处理。只问进度时不自动执行下一阶段。用户不必手写JSON或哈希，助手负责根据真实输入生成工具清单。

## 三类完整工作包

- **观察性研究**：方案与字典 → 数据充分性 → 获批分析 → 结构化结果 → 论证/章节 → STROBE及适用扩展 → 证据与正文对账 → 审阅稿。图表、分母和分析人群绑定同一结果版本。
- **随机试验**：方案/注册/获批SAP → 实际执行记录与结果 → 注册结局对照 → 章节 → 当前CONSORT及扩展 → 证据、流程和数字对账 → 审阅稿。不要把注册与伦理信息缺失补写成已完成。
- **系统综述**：检索协议 → 数据库原生记录 → 导入/去重 → 独立筛选与原因记录 → 报告/研究区分 → 提取/适用偏倚工具 → 获批合成 → PRISMA核对 → 正文与证据对账 → 审阅稿。检索partial不能变成完整覆盖。

以上是可选工作顺序，已有可靠上游产物可直接进入相应步骤；普通翻译或局部修订不强制跑完整包。
