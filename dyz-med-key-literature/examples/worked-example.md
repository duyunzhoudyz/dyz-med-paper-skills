# dyz-med-key-literature 完整示例（教学演示）

> **本示例为教学演示，涉及的研究课题、文献、证据等级判断均为虚构，不对应任何真实已发表研究，仅用于
> 演示 dyz-med-key-literature 的工作方式。**

## 场景

用户已通过 `/dyz-med-cnki`（虚构过程）拿到一份候选文献池，共15篇（虚构），研究主题为"某新型抗凝药物对
房颤患者卒中预防效果"（虚构课题）。用户说："帮我从这些文献里挑出最关键的几篇精读一下。"

## Step 1：分级排序（虚构示例）

从候选池中识别：
- 1篇虚构的Cochrane系统综述（"Novel anticoagulant X for stroke prevention in AF: a systematic
  review"，虚构，PMID: 00000010占位）→ 判断为指南级证据，高优先级精读。
- 1篇虚构的高被引RCT（虚构引用数 320）→ 高优先级精读。
- 2篇虚构的观点矛盾文献（一篇支持、一篇提出安全性顾虑）→ 标记为 `contradictory`，需要精读以便讨论
  部分平衡呈现。
- 其余文献按相关性归为背景引用，暂不深度精读。

## Step 2：深度精读简报（虚构示例片段，`key-paper-briefs/brief-000010.md`）

```
# 精读简报：Novel anticoagulant X for stroke prevention in AF（虚构）

- PMID: 00000010（虚构占位）
- 研究设计：系统综述 + meta分析（虚构）
- 人群：非瓣膜性房颤患者（虚构）
- 关键发现（虚构）：相较华法林，卒中风险比 HR 0.79（95%CI 0.68-0.92，虚构数值）
- 局限性（虚构）：纳入研究异质性较高，亚组分析证据有限
- 对本稿的用途：可作为引言背景的核心引用，也可在讨论部分与本研究结果比较
- 全文获取状态：full_text_read（虚构：已存档于 paper/evidence/fulltext/pmid00000010.pdf）
```

## Step 3：前沿综合（虚构示例片段，`frontier-literature-synthesis.md`）

```
## 支持性发现（虚构）
多数纳入文献支持新型抗凝药物在卒中预防效果上不劣于传统治疗。

## 矛盾发现（虚构）
1篇虚构文献提出真实世界数据中出血风险可能被低估，需要在讨论部分明确回应，不能回避。

## 方法学借鉴点（虚构）
系统综述采用的亚组分析框架（按年龄/肾功能分层）值得本研究方法部分借鉴。

## 缺口含义（虚构）
现有证据对高龄合并肾功能不全人群的数据仍然有限，本研究可在此填补部分缺口，但缺口程度不应夸大表述。
```

## 小结

本示例展示了从候选池分级 → 精读简报 → 前沿综合的完整链路，特别演示了"矛盾证据不能被淡化或省略"这一
关键要求。所有文献标题、PMID、数值均为虚构占位，实际使用时必须替换为真实精读产出的内容。
