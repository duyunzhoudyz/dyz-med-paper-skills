# 示例：从相关性到机制层级的推导（虚构）

## 输入

用户描述（虚构）："我们观察到老年髋部骨折术后患者中，血清IL-6水平升高的人似乎更容易出现术后认知
功能障碍（POCD），但这只是我们科室的印象，不确定这个说法算不算'机制'。"

## Mode 1：Question Upgrade

**当前层级**：association（仅有临床印象式的相关性观察，尚无系统证据、也无机制阐释）

**核心薄弱环节**：只是"印象"，既没有系统的统计关联验证，也没有说明IL-6如何导致认知功能障碍的路径。

**升级后主问题（虚构）**：在老年髋部骨折患者中，术后早期（24-48小时）血清IL-6水平升高，是否通过
神经炎症反应介导术后认知功能障碍的发生？

**递进子问题**：
1. 术后IL-6水平与POCD发生率是否存在统计学关联（关联层面，队列研究可回答）？
2. 若关联存在，是否有神经炎症标志物（如S100B、GFAP）的中介证据支持机制路径（机制层面）？
3. 若机制成立，围术期抗炎干预是否能降低POCD发生率（转化层面，需要干预性研究）？

**最小需要的证据**：至少完成子问题1的队列关联分析，并有文献支持IL-6→血脑屏障通透性→神经炎症这一
生物学合理性，才能在讨论部分使用"提示性机制"表述；子问题2、3超出本单位现有数据能回答的范围。

## Mode 2：Mechanism Chain Check

| Node | Current Claim | Evidence | Gap | Required Fix |
|---|---|---|---|---|
| Clinical problem | 老年髋部骨折术后POCD高发 | 科室观察 + 既往流行病学数据（虚构引用） | 无本单位系统数据 | 先做描述性统计 |
| Upstream driver | 手术应激 → 全身炎症反应 | 文献支持全身炎症反应普遍存在（虚构引用） | 未测量本队列全身炎症全貌 | 补充CRP等指标 |
| Mediator | IL-6 → 血脑屏障通透性增加 | 动物实验证据（虚构引用），人体证据有限 | 人体机制证据薄弱 | 标注为plausible inference |
| Executor | 神经炎症 → 海马区功能受损 | 主要来自动物模型 | 缺乏人体影像/标志物直接证据 | 标注为speculative |
| Phenotype | POCD（认知评分下降） | 本队列可测量 | 结局定义需标准化 | 采用统一POCD诊断标准 |
| Validation path | 拟通过队列关联 + 亚组分析验证 | 设计中 | 样本量待估算 | 补充样本量计算 |
| Translational value | 若成立，提示围术期抗炎可能获益 | 无 | 无干预数据 | 明确本研究不支持因果/干预结论 |

## 输出：Mechanism Logic Report（虚构）

```markdown
## Mechanism Logic Report

### Current Level
association（观察阶段），部分链条节点为 plausible inference / speculative

### Main Weakness
临床印象尚未经过系统统计验证；IL-6→神经炎症→POCD这条链条在人体层面证据薄弱，多来自动物模型外推

### Upgraded Research Question
老年髋部骨折患者术后早期IL-6水平升高是否与POCD发生存在统计学关联（关联层面为主，机制表述需谨慎）

### Mechanism Chain
（见上表）

### Translational Value
若关联成立，可为后续抗炎干预研究提供假设生成依据；本研究本身不支持因果或干预建议

### Next Minimum Action
1. 先完成队列关联分析（IL-6与POCD发生率）
2. 讨论部分机制表述统一标注为"plausible inference"，避免"IL-6导致POCD"这类因果语言
3. 如需验证机制，需设计追加神经炎症标志物检测的前瞻性研究
```
