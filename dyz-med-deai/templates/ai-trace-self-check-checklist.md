# 医学论文机械化文风自查清单

> 这是一份编辑清单，不是 AI 检测器。单个语言特征不能证明文本来源。

## 信息与证据

- [ ] 是否出现原始结果中没有的数字、效应量、机制或限制？
- [ ] 观察性研究是否被改成因果或疗效表述？
- [ ] 否定、条件和不确定性是否在改写后仍存在？
- [ ] 引用、图表编号、伦理、注册和 AI 使用披露是否完整保留？

## 语言

- [ ] 是否反复使用“结果表明”“值得注意的是”等不承载信息的包装？
- [ ] 是否堆叠 furthermore、moreover、notably 等连接词或强调词？
- [ ] 是否用“重要、显著、突破性”等评价替代了具体结果？
- [ ] 是否连续重复相同句式、三点结构或段落开头？
- [ ] 是否存在主语不清、过长句、同义反复或术语漂移？
- [ ] 是否在同一句叠加多个模糊词，反而掩盖真实不确定性？

## 医学写作专项

- [ ] 结果部分是否混入机制、文献比较或临床建议？
- [ ] 图表是否反复作主语，而不是先陈述发现再引用图表？
- [ ] “未发现统计学差异”是否被误写成“无效”或“等效”？
- [ ] 预测性能是否被误写成临床可用性？
- [ ] 局限性是否与方法实际做法相冲突？

## 完成标准

- [ ] 改写覆盖原文全部信息点；
- [ ] 受保护数字与引用逐项一致；
- [ ] 没有故意制造错误、口语或“人类瑕疵”；
- [ ] 没有承诺通过 AI 检测；
- [ ] 实质性科学问题已另列给作者决定。
