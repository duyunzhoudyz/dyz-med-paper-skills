# 示例：他汀类药物使用与术后谵妄风险队列研究的论证地图构建（虚构）

## 输入（虚构）

- `project-passport.yaml`：回顾性队列，PECO = 心脏手术患者(P) / 术前他汀类药物使用(E) / 未使用(C) /
  术后谵妄发生率(O)
- `structured_results.yaml`（虚构）：他汀组谵妄发生率12%，对照组18%，校正OR=0.61（95%CI 0.42-0.89）
- `key-literature-map.yaml`（虚构）：已有2篇观察性研究报告类似关联，但均为小样本单中心；无RCT
  直接验证

## 输出：manuscript_argument_map（节选，虚构）

```yaml
research_question: "心脏手术患者术前他汀类药物使用是否与术后谵妄发生率降低相关"
core_claim: "术前他汀类药物使用与较低的术后谵妄发生率相关（校正OR=0.61）"
known_before: "既往2项小样本观察性研究提示他汀可能与术后谵妄风险降低相关（虚构引用）"
gap: "既往研究样本量小、单中心，缺乏充分校正混杂的大样本证据"
added_by_this_study: "更大样本量的回顾性队列 + 多变量校正分析"

evidence_support:
  - claim: "他汀组谵妄发生率显著低于对照组"
    supporting_result: "校正OR=0.61 (95%CI 0.42-0.89), 引自 structured_results.yaml"
    strength: "moderate"   # 观察性设计，非RCT，强度不宜标为strong

claim_boundaries:
  - claim: "他汀类药物降低术后谵妄风险"
    allowed_language: "他汀类药物使用与较低的谵妄发生率相关（associated with）"
    prohibited_language: "他汀类药物降低/预防谵妄（causes / prevents）"
    design_reason: "回顾性队列设计存在未测量混杂可能，不支持因果结论"

literature_intelligence_status: "available"

section_thesis:
  introduction: "术后谵妄是心脏手术常见并发症，他汀类药物的潜在保护作用证据有限且样本量不足"
  methods: "回顾性队列设计，如何定义暴露组和结局，如何校正混杂"
  results: "他汀组谵妄发生率更低，校正后关联仍显著，不做因果解释"
  discussion: "结合既往小样本研究比较，讨论可能机制（抗炎/血管保护）为plausible inference而非定论，
    强调观察性设计局限"
  abstract: "浓缩以上内容，结论语言与discussion的claim_boundaries保持一致"
```

## 输出：section_plans.discussion（节选，虚构）

```yaml
discussion:
  paragraphs:
    - role: "关键结果总结"
      content_hint: "他汀使用与谵妄发生率降低相关（校正OR=0.61）"
    - role: "与已知文献比较"
      required_sources: ["key-literature-map.yaml 中的2篇既往观察性研究"]
    - role: "机制解释（受claim_boundaries约束）"
      content_hint: "可能通过抗炎/内皮保护机制（plausible inference，需标注为推测性，
        不引用未直接验证的机制文献作为定论）"
      blocked_language: ["他汀类药物预防谵妄"]
    - role: "局限性"
      content_hint: "回顾性设计、未测量混杂（如术前认知基线）、单中心"
```

## 下游使用

`/dyz-med-discussion` 撰写讨论部分时，直接读取上述 claim_boundaries 和 section_plans.discussion，
确保机制段落使用"plausible inference"而非因果宣称语言；`/dyz-med-abstract` 撰写摘要结论时同样受
claim_boundaries 约束，避免摘要结论强度超过正文。
