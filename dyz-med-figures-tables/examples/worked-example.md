# 完整示例：图表-正文数值一致性核对（虚构教学示例）

本示例为教学演示，涉及的研究课题、数据、数值均为虚构，不对应任何真实已发表研究。

## 背景（虚构）

延续前述虚构队列研究示例。稿件草稿的"结果"部分写道："治疗组心血管事件风险显著降低（HR 0.72，
95% CI 0.54–0.93，P=0.013，事件数87例）"。同时本次实际执行的分析输出及其日志记录：
HR=0.71，95%CI[0.54, 0.93]，P=0.013，事件数86例。
Table 1（表格文件）里显示总样本量N=500，与正文一致。

## 第1步：Phase 1 — 确定研究类型需要的图表

研究类型为队列研究 → 按对照表，需要：Table 1（基线特征）、主要回归结果表、敏感性分析表、
STROBE流程图，可选Kaplan-Meier曲线。本例假设Table 1、回归表、STROBE流程图、KM曲线均已生成。

## 第2步：Phase 3 — 交叉一致性核对（使用 templates/figure-text-consistency-checklist.md）

| 数值描述 | 表/图中的值 | 正文中的值 | 已执行分析输出中的值 | 状态 |
|---------|------------|-----------|-------------------------------|------|
| 主要结局HR | 0.71（回归表） | 0.72 | 0.71 | **MISMATCH**（正文与表/YAML不符） |
| 95% CI | [0.54, 0.93] | [0.54, 0.93] | [0.54, 0.93] | MATCH |
| 事件数 | 86（回归表） | 87 | 86 | **MISMATCH**（正文与表/YAML不符） |
| Table 1总N | 500 | 500 | 500 | MATCH |
| KM曲线风险集人数（12月） | 214 | 未在正文提及 | — | NOT CITED（图存在但正文未引用具体数字，不算错误，仅提示） |

## 第3步：输出核对报告

```
┌──────────┬──────────────────┬──────────┐
│ Check    │ 正文 vs 结构化结果 │ Status   │
├──────────┼──────────────────┼──────────┤
│ HR       │ 0.72 vs 0.71     │ MISMATCH │
│ 事件数    │ 87 vs 86         │ MISMATCH │
│ 95% CI   │ 一致             │ MATCH    │
│ Table1 N │ 一致             │ MATCH    │
└──────────┴──────────────────┴──────────┘

发现2处 MISMATCH。先确认结构化结果、回归表和运行日志来自同一数据版本与同一次成功执行，再修改正文；
不能仅因为某个文件标为“结构化结果”就自动当作真值。
```

## 第4步：作者处理（虚构）

作者核实后发现是正文撰写时手误多算了1个事件、HR四舍五入时看错了小数位，修正正文为"HR 0.71，
95% CI 0.54–0.93，P=0.013，事件数86例"，与图表和结构化结果保持一致。

## 第5步：图注生成示例

"Figure 2. 治疗组与对照组的Kaplan-Meier生存曲线（1年内心血管事件）。风险集人数在图下方标注。
缩写：HR，风险比；CI，置信区间。"（虚构示例文字，仅演示格式）
