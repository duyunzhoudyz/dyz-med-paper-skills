# 图表-正文数值核对清单模板

用途：逐个数值核对图/表/正文三处是否一致，包括数值本身、单位、有效数字位数，避免"图上写HR=0.71，
正文写HR=0.72"这类常见的稿件疵瑕。

## 1. 逐数值核对表

| 数值描述 | 表/图中的值 | 正文中的值 | 已执行分析输出中的值 | 单位一致 | 舍入一致 | 状态 |
|---------|------------|-----------|-------------------------------|---------|-------------|------|
| 例：主要结局HR | 0.71 | 0.71 | 0.71 | 是 | 是（均2位小数） | MATCH |
| 例：Table 1总N | 500 | 500 | 500 | — | — | MATCH |
| 例：事件数 | 86 | 87 | 86 | — | — | MISMATCH（正文与表/YAML不符） |

状态取值：MATCH / MISMATCH / MISSING_SOURCE / NOT_CITED / MISSING_FILE。

## 2. 单位一致性专项检查

| 变量 | 图/表中单位 | 正文中单位 | 是否一致 |
|------|------------|-----------|---------|
| 例：体重 | kg | kg | 是 |
| 例：血压 | mmHg | mmHg | 是 |
| 例：随访时间 | 月 | 天 | 否——需统一 |

## 3. 有效数字位数一致性专项检查

| 数值类型 | 图/表位数 | 正文位数 | 是否一致 | 建议 |
|---------|----------|---------|---------|------|
| P值 | 3位小数 | 2位小数 | 否 | 按目标期刊当前要求统一；保留足以核对的精度 |
| HR/OR/RR | 2位小数 | 2位小数 | 是 | |
| 百分比 | 1位小数 | 整数 | 否 | 建议统一 |

## 4. 图表编号与引用核对

- [ ] 正文中引用的每个图/表编号，对应文件都存在
- [ ] 已生成的每个图/表文件，正文中都有引用（无"孤儿图表"）
- [ ] 图表编号连续，无跳号

## 5. 汇总

| 检查类别 | 通过数 | MISMATCH数 | 备注 |
|---------|--------|-----------|------|
| 数值一致性 | | | |
| 单位一致性 | | | |
| 有效数字一致性 | | | |
| 编号与引用 | | | |

## 6. 处理建议

发现 MISMATCH 时，标注为“需在定稿前核实”，并追溯实际执行脚本、运行日志和结果文件。结构化结果也可能
来自旧运行或错误脚本，不能未经核实自动当作真值。
