# 数据充分性方法学参考

- **STROBE**：观察性研究报告规范。用于核对参与者、变量、偏倚、缺失数据、混杂控制和敏感性分析是否被透明报告；它不是因果识别工具。

- **TRIPOD+AI**：回归或机器学习预测模型的报告规范。用于检查数据来源、样本量、缺失、模型开发、验证和性能报告。  
  https://www.equator-network.org/reporting-guidelines/tripod-statement/

- **GRADE**：评价某结局的证据体确定性。不得将 GRADE 的高、中、低、极低直接替换为本技能的描述性、关联性、因果推断或预测性论断上限。

- **Cochrane Handbook**：缺失数据、偏倚和敏感性分析的方法学参考。具体处理必须结合研究设计和缺失机制，不能只按缺失比例机械选择方法。

- **因果推断基本假设**：观察性因果分析需讨论时间顺序、可交换性、一致性、正值性、测量误差和未测量混杂。复杂模型不能替代这些假设。

## 边界

本技能评估数据与计划问题是否匹配，不模拟某个期刊的录用标准，也不根据样本量承诺期刊分区。目标期刊的具体要求应另行核实。
