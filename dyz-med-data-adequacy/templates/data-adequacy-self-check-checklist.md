# 数据充分性自评清单（骨架模板）

> 用途：作为人工判断“数据是否够用”的起点。
> 逐项填写，所有判断都应基于研究设计最佳实践和真实数据情况，不要预先假设某个具体期刊或分区"要求"
> 某一项。

## 1. 研究类型与可支持论断

- 研究类型（来自 `/dyz-med-init`）：<描述性研究 / 观察性关联研究（队列/病例对照/横断面）/ 干预性研究
  （RCT）/ 诊断准确性研究 / 预测模型研究 / 系统综述等>
- 基于当前设计、执行和数据质量，初步可支持的论断：<描述性 / 关联性 / 因果推断候选 / 预测性 / 不支持>
  - 说明：论断上限由设计、时间顺序、测量、缺失、偏倚和识别假设共同决定，不由数据量或统计方法
    自动“升级”。横断面数据通常不能建立清晰时间顺序。

|---|---|---|

## 4. 数据异常清单（如实呈现，不默认数据正确）

逐项列出任何统计学或临床可信度存疑的模式，标记为需要临床医生确认的问题，不要自行假设合理或错误：

- <例：某组100%出现同一类并发症，是否符合临床预期？>
- <例：切除范围更小的亚组反而并发症率更高，是否有编码错误或存在未测量的混杂？>
- <例：某组结局事件为零，是否为真实的零事件还是数据未采集完整？>

## 5. 结论：scope_decision

- [ ] `upgrade_pending`：用户/临床医生将补充数据后重新评估。
- [ ] `accepted_ceiling`：用户接受当前可达证据等级上限，继续分析和写作。
- [ ] `not_feasible`：当前数据无法回答主要问题，需要换问题或重设计。
