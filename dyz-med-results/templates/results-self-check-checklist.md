# 结果段落自查清单

用途：结果部分初稿写完后，逐条过一遍。所有条目都是建议性提醒，供作者自行判断是否采纳，不是自动
删除或强制阻断的规则——发现问题时的处理方式是"标记+建议",最终怎么改由作者决定。

## A. 呈现顺序

- [ ] 是否按"基线特征 → 主要结局 → 次要结局 → 敏感性分析 → 亚组分析 → 事后探索性分析"的推荐顺序排列？
      如果顺序不同，是否有明确理由（例如期刊模板要求）？
- [ ] 主要结局是否清晰可辨（不是混在次要结局堆里，读者一眼能找到）？

## B. 数值一致性

- [ ] 是否以稳定`analysis-results`工件ID映射真实路径/version/sha256，而非强制某个文件名？
      既有`structured_results.yaml`和`analysis-results.json/yaml`均保留路径，不为统一名称重跑分析。
- [ ] 正文效应量、CI、P值是否与该analysis_id的实际输出一致？非整数默认精确比较，展示舍入逐值声明
      小数位数及half_up/half_even规则；计数严格相等且不允许容差，236与235必须标冲突。
- [ ] 人群、结局、时间点、比较组/参考组方向、单位及分母口径是否逐项匹配？不自动换算HR/OR/RR。
- [ ] 正文提到的样本量/事件数（n_total / n_events）是否与 Table 1、流程图（如有 `/dyz-med-flowchart`
      产出）里的数字一致？
- [ ] 如果同一结局在正文和图/表里都出现了数字，两处是否一致（建议交给 `/dyz-med-figures-tables` 再做一次
      交叉核对）？

### 机器对账回执（如执行）

- [ ] 是否按[输入合同](results-section-skeleton.md#结构化对账输入合同)整理了结果JSON及有定位的
      reported-values JSON？来源输出和实际稿件均登记版本/字节哈希；外部有效统计结果可以直接使用。
- [ ] 来源可追溯且分析已执行？缺来源、未执行或未知状态必须unverified，数值相等也不能自动通过。
- [ ] null字段有真实不适用理由，未提供与不适用分开？P和CI分别记录方法及调整口径，允许合法的
      调整P值/未调整CI共存，不机械推算显著性是否“匹配”。
- [ ] 运行命令、实际退出码与报告/独立check路径已记录？0仅清单范围consistent，1为差异，3为未核实，
      2为参数/执行/输入绑定错误；completed不等于科学通过。差异和未核实项同时出现时两者均保留。
- [ ] 工具未改原结果/稿件、未运行模型？报告写新路径，独立check引用报告真实哈希，输入变化后另建检查。
- [ ] coverage的未覆盖分析和清单完整性已人工复核？工具不是Word/PDF通用提取器，不认证定位语义、
      人工摘录、模型适用性或科学解释；不得把局部一致扩大为全文通过。

## C. 调整集透明度

- [ ] 每一条主要/次要结局的效应量，是否都注明了对应的调整变量集（例如"调整年龄、性别、BMI……后"）？
      审稿人通常会主动核对这一点，缺失调整集的表述建议补全。
- [ ] 调整集本身是否与 `02-methods.md` 里记录的模型设定一致？

## D. 解读性措辞检查（建议检查，而非强制删除）

- [ ] 是否出现了"suggests / indicates / interestingly / consistent with previous studies"一类
      解读性措辞？这类表述按惯例更适合放进讨论部分，建议标记出来，问作者是否要移动，而不是直接删掉——
      作者可能想保留这个观察点，只是换个位置。
- [ ] 是否有对"为什么会出现这个结果"的机制性猜测出现在结果部分（这类内容通常属于讨论部分）？

## E. 亚组与事后分析标注

- [ ] 亚组分析是否报告各亚组效应估计与置信区间，并用交互检验评价组间差异，而不是比较各组内部
      P值是否分别显著？
- [ ] 未在方法部分/统计分析计划里预先设定的分析，是否建议标注为"事后探索性分析"？（具体措辞由作者
      决定，这里只建议标注这件事本身，不规定固定句式）

## F. 图表标题格式

- [ ] 图题是否放在图的下方？
- [ ] 表题是否放在表的上方？
- [ ] 标题是否具备描述性（不是简单写"Figure 1"了事）？

## G. 临床意义语言（若已有 /dyz-med-interpret 分级结果）

- [ ] 临床意义措辞是否与已有 `/dyz-med-interpret` 解释记录一致，并按下方H节回查实际效应、区间和阈值？
      上游标签与实际数值冲突时标出冲突，不沿用错误档位。
- [ ] 缺少可信阈值或尺度不匹配时，是否标为 `indeterminate`，只陈述效应大小和精确度？缺少解释记录时
      可以建议作者使用 `/dyz-med-interpret`，但不擅自补写临床意义判断或运行新分析。

## H. 关键结论反查

结果概括、摘要标题和结论共用此检查。复用结果来源表；已有论断证据矩阵时沿用同一论断ID与来源定位，
只补充判断依据，不另建一份统计事实库。逐条关键句记录：

| 关键句/论断ID及稿件位置 | 实际输出定位（效应量、CI、尺度/方向、时间点） | 结局角色及预设/探索状态 | 研究设计与推断边界 | 临床阈值、来源及适用性（如涉及） | 判断、缺项及建议措辞 |
|---|---|---|---|---|---|
| 待填写 | 待核实；不从正文反造结果 | 主要/次要/探索性 | 待填写 | 不适用/可信阈值及来源/未知 | 已核对/冲突/待核实，并写明理由 |

- [ ] 关键句能否由该项实际效应与整个CI支持，且未把次要或探索性结果写成预设主要结论？按分析计划
      说明P值与CI的报告口径，不机械要求所有调整P值都有配套调整CI。
- [ ] 临床判断是否使用同尺度、方向和时间点的可信阈值？点估计越过但CI跨阈值为 `uncertain`；整个CI
      越过重要获益阈值仅与临床重要获益相容；阈值未知或不适用为 `indeterminate`。边界等于阈值不算已排除。
- [ ] 非显著结果是否保留CI所容许的效应，而非写成“无效”“等效”或仅凭P值推断“检验效能不足”？
- [ ] 因果强度是否符合设计和实际识别依据？观察性关联不能仅凭调整后显著而升级为干预有效或因果关系；
      不按单个动词自动裁定。涉及模型适用性时引用已有诊断证据；资料不足标为 `unverified`，不是证明模型无效。

发现冲突时保留原输出，标记受影响句并建议有依据的改写；缺诊断或阈值不妨碍明确受限的描述性草稿，
但不能宣称相应推断已核实。
