# 医学稿件导出前后核对清单

## 输入与版本

- [ ] 已记录项目根目录、所有输入的稳定 artifact_id/path/version/sha256、用途与实际纳入范围；
- [ ] 按 R2 schema 1.1 逐条核对相关 checks 的 inputs、scope、execution_status、applicability、domain_result、report、checked_at 与验证输出 freshness；
- [ ] 无 passport 时使用同形独立记录，未强制其他技能或全流程执行；
- [ ] 源文件只读，输出写入新目录；
- [ ] 主稿、匿名稿、标题页和补充材料的拆分方式符合目标期刊要求。

## 内容一致性

- [ ] 方法、结果、摘要和表格中的 N、事件数、效应量、CI、P 值一致；
- [ ] 主要结局、组名、单位和时间点一致；
- [ ] 预设与探索性分析标记一致；
- [ ] 无占位符、重复章节或重复参考文献块；
- [ ] 已知差异已解决，或审阅版已显著标记。

## 科学状态与审阅版用途

- [ ] 材料/格式完整性、科学结论及 current/stale/unverified、外部授权分列；
- [ ] 校验器退出码 0、文件齐全和导出成功均未被当作科学 PASS；
- [ ] 当前 REJECT/REVISE、critical/major 未结、缺失/未运行/有限/失效检查均显式列出，未无保留标为终版；
- [ ] 已明确要求带问题审阅版时可按该范围继续，不强制重跑所有检查；
- [ ] 文件名、首页、manifest 标“内部审阅版／非投稿终版”及具体未结限制；
- [ ] verified_closed 引用 current/completed/applicable 的 verification_check_id 与 evidence.path/sha256，且结论支持关闭；已回应不算已关闭；
- [ ] 导出副本另登记工件；纯排版字节改变也不沿用旧绑定，沿用科学判断须新检查及内容等价/定位重核依据。

## 外部处理与同意预检

- [ ] 已辨别工具是否本地；连接状态不等于外传授权；
- [ ] 外部处理前记录内容类别、用途、服务/接收方与目的地、获准字段/文件范围和当前人类来源；
- [ ] 按 R2 human_approvals 核对 state、targets 版本/哈希、role、confirmed_at、source 的 human/actor_id/statement/reference/locator，并人工核实权限；
- [ ] 仅导出授权不等于外部转换授权；任一信息未知时发送数为 0，采用已确认本地工具或 Markdown 降级；
- [ ] 内容/用途/目的地/范围变化已重新确认，recorded_not_authenticated 未当作合法授权认证；
- [ ] 回执记预检时间、授权依据、实际发送工件/字段、目的地、时间、执行状态、返回证据/限制；未发送据实记录，不复制敏感正文；
- [ ] 研究参与同意与患者发表同意分别核实，适用性不明交有资质人员复核，未推定批准或豁免。

## 参考文献

- [ ] 每个正文引用有对应记录；
- [ ] 每条引用记录至少有足够的可核查书目信息；
- [ ] DOI/PMID 等标识符在适用时已核实；书籍、标准和网页不因缺 DOI/PMID 被错误删除；
- [ ] 引用样式与目标期刊当前要求一致。

## 图表与附件

- [ ] 每个正文图表引用都对应真实文件或 Word 表格对象；
- [ ] 编号连续，题注和脚注一致；
- [ ] 文件格式、尺寸、分辨率和颜色符合目标期刊具体要求；
- [ ] 不使用“通常 300 DPI”等经验值替代期刊规则；
- [ ] 匿名版已清除图表中的作者/机构身份信息（如期刊要求）。

## 排版

- [ ] 页面、字体、行距、行号和标题层级符合要求；
- [ ] 中文字体、数学符号和特殊字符显示正确；
- [ ] 表格样式仅在期刊要求时使用三线表等特定格式；
- [ ] 无意外空页、断行、超出页边距或损坏图片。

## 成品

- [ ] 文件可打开，页数和大小合理；
- [ ] 视觉检查已完成，或已说明无法完成；
- [ ] 输出哈希、版本、格式和降级情况已写入 manifest；
- [ ] 导出未被描述为投稿完成或科学审核通过。
