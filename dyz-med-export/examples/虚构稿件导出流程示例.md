# 医学稿件导出示例

## 输入

- 五个 Markdown 章节；
- BibTeX 参考文献库；
- 两张表和一张图；
- 一本虚构期刊的官方 Word 模板；
- 输出要求：匿名审阅版 DOCX 和 PDF 预览。

## 预检

发现：

- Methods 与 Table 1 的总样本量均为 120；
- Abstract 的主要效应量与 Results 一致；
- 一条正文引用没有对应 BibTeX 记录；
- 图 2 在正文被引用，但文件未提供。

系统不修改源章节，也不虚构参考文献或图片。它生成 `export-discrepancies.md`，并给作者两种选择：

1. 补齐引用和图 2 后生成投稿候选版；
2. 先生成带明显 `REVIEW-DRAFT` 标记的审阅版。

## 导出

作者选择先补齐材料。系统探测当前环境的文档转换能力，使用实际可用的路径和期刊模板，在新目录中合并副本、
渲染引用、嵌入表图并生成版本化 DOCX。源文件保持不变。

## 验证

- DOCX 可正常打开；
- 标题、摘要、正文、参考文献和补充材料顺序正确；
- 匿名版没有作者与单位；
- 图表、编号和正文引用对应；
- 无占位符、重复参考文献或断链；
- PDF 仅作为视觉预览，状态未被描述为“已投稿”。
