# 格式排版与引用参考

- **目标期刊当前 Instructions for Authors 与官方模板**：稿件拆分、篇幅、表图、匿名审稿和文件格式的
  首要依据。
- **ICMJE Recommendations**：医学稿件准备、参考文献准确性和投稿透明度的一般建议。
- **NLM Citing Medicine**：Vancouver/NLM 风格参考文献格式的权威参考之一。
- **GB/T 7714**：部分中文期刊采用的参考文献著录标准；是否适用及采用哪个版本以目标期刊要求为准。
- **SAMPL 等统计报告建议**：用于核对统计量呈现的一致性，但导出阶段不重新分析数据。
- **目标期刊图像规范**：图片格式、尺寸、分辨率和可接受处理边界必须逐刊核对，不设通用固定 DPI。

排版工具、CSL 文件和转换程序只负责格式。引用样式正确不等于文献真实，文件成功生成也不等于内容通过审核。
