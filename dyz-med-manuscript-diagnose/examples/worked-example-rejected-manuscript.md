# 示例：一份虚构被拒稿件的诊断

## 场景
虚构课题："某新型床旁超声评分对急诊脓毒症患者预后预测价值的前瞻性队列研究"（虚构）。用户粘贴了一封
虚构期刊的拒稿信和稿件全文，说："这篇被拒了，帮我看看接下来该怎么办。"

## Phase 0-1：解析与资产盘点（节选）

| 章节 | 状态 | 备注 |
|------|------|------|
| 标题 | PRESENT | |
| 摘要 | PRESENT | 结构化摘要，但结论句有因果语言 |
| 引言 | PRESENT | |
| 方法 | NEEDS WORK | 缺失样本量计算依据 |
| 结果 | PRESENT | |
| 讨论 | PRESENT | |
| 表格 | PRESENT (N=3) | |
| 图片 | MISSING | 未见预后曲线图（如Kaplan-Meier） |
| 参考文献 | PRESENT (N=28) | |
| 伦理声明 | PRESENT | |
| 数据共享声明 | MISSING | |
| AI使用披露 | NOT ASSESSED | 仅凭文风不能判断是否使用AI；需由作者说明实际使用情况 |
| CRediT作者贡献 | MISSING | |
| 利益冲突声明 | PRESENT | |
| 基金资助声明 | PRESENT | |

完整度：11/15 章节已具备。

## Phase 2-3：稿件类型与阶段判定
- 稿件类型：预后研究（prognostic study）
- 当前阶段：**REJECTED**（已收到拒稿决定）
- 语言：中文为主，中译英尚未开始

## Phase 5：风险分级示例

- **[CRITICAL]** — 摘要结论"该评分可预测并降低患者死亡风险"存在因果表述，但研究设计为前瞻性队列
  观察性研究，无法支持"降低风险"这类干预性因果结论 → 建议改为"该评分与死亡风险升高相关，具有潜在
  预测价值"，并在讨论局限性中说明观察性设计的因果推断限制。
- **[MAJOR]** — 当前材料未说明是否使用过AI辅助工具。文风不能证明使用与否 → 建议由作者确认实际
  使用情况；如确有使用，再按目标期刊当前政策准备披露。语言是否模板化可另用 `/dyz-med-deai` 改善，
  但不得把语言自然化当作披露替代品。
- **[SOFT WARNING]** — 方法部分未说明样本量计算依据 → 建议补充样本量估算的具体方法和参数。
- **[SUGGESTION]** — 建议补充一张预后曲线图（如Kaplan-Meier生存曲线），增强结果可视化。

## Phase 6：期刊就绪度与优先级

- 就绪度：**NEEDS MAJOR REVISION**
- 最高优先级：修正因果语言、由作者确认实际AI使用情况
- 应当修复：补充样本量依据、数据共享声明、CRediT作者贡献
- 可选打磨：增加预后曲线图

## Phase 8：建议下一步
→ `/dyz-med-revision`（REJECTION_RECOVERY 模式，处理被拒后的修订与改投策略）
→ 之后建议运行 `/dyz-med-guideline`（确认TRIPOD+AI或相关预后研究报告规范的条目覆盖情况）
