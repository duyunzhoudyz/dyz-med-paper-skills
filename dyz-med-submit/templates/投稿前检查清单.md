# 医学稿件投稿前检查清单

## 期刊要求

- [ ] 文件清单来自目标期刊官方当前说明，并记录访问日期；
- [ ] 文章类型、匿名审稿、文件命名和在线表单要求已确认；
- [ ] 没有把其他期刊的固定附件清单套用过来。

## 作者

- [ ] 姓名、顺序、单位、通讯信息和 ORCID 已由作者确认；
- [ ] 每位作者的署名资格、贡献、终稿批准和责任承担已确认；
- [ ] CRediT 角色反映实际贡献，不由工具推断；
- [ ] 需要签字或作者本人填写的表单已列为人工步骤。

## 伦理与透明度

- [ ] 伦理审批/豁免和研究参与知情同意信息来自真实文件；
- [ ] 患者发表同意独立记录；病例、可识别叙述/影像等适用性由有资质人员结合期刊要求复核；
- [ ] 未把参与同意、伦理批准或去标识化推定为发表同意/豁免，未知项标待专业复核；
- [ ] 注册号、平台和时间已核实（如适用）；
- [ ] 每位作者的利益冲突状态区分“已确认无”与“尚未询问”；
- [ ] 资助来源及资助方角色真实；
- [ ] 数据与代码可用性符合隐私、伦理和协议限制。

## AI 使用

- [ ] 实际使用的工具、版本、用途和人工复核方式已由作者确认；
- [ ] 披露位置与措辞符合目标期刊当前政策；
- [ ] 未使用时不虚构披露，已使用时不删除或弱化；
- [ ] AI 未被列为作者。

## 稿件与附件

- [ ] 主稿版本、摘要、表图和补充材料一致；
- [ ] 标题页与匿名稿拆分正确；
- [ ] 投稿信不含无法证明的“首次”或夸大结论；
- [ ] 无未标注占位符、示例姓名、虚构邮箱或虚构编号。

## 三轴就绪报告

- [ ] package_completeness 分列 complete/incomplete/unknown，仅代表文件及行政材料；
- [ ] scientific_review 列 supported_for_declared_scope/not_ready/unverified，并逐条保留科学结论、范围和 freshness；
- [ ] external_authorization 按动作/目的地列 not_confirmed/confirmed/declined、来源、范围和当前有效性；
- [ ] 读取 R2 schema 1.1 工件 ID/path/version/sha256、checks 的 inputs/scope/execution_status/applicability/domain_result/report/checked_at 及逐条验证输出 current/stale/unverified；
- [ ] current 或校验器退出码 0 不是科学 PASS；未用全局退出码触发强制全流程；
- [ ] 当前 REJECT/REVISE、critical/major 未结、缺失/过期/未执行/有限范围检查或未确认源事实时，readiness 为 not_ready；材料齐全不覆盖这些限制；
- [ ] ready 仅用于证据支持当前范围且必需材料/事实齐全的本地候选包，不是外部执行许可；ready_with_manual_steps 仅剩已列明机械步骤，不能掩盖科学/事实问题；
- [ ] 已回应数与当前有效验证关闭数分列；verified_closed 有 current/completed/applicable 的 verification_check_id、支持关闭的实际结论及 evidence.path/sha256；
- [ ] 版本/字节变化后旧检查和批准不再直接沿用；纯排版也需新绑定与等价性/定位复核，保留历史；
- [ ] 不满足条件仍可生成显著标记“内部审阅包／非提交终版”的本地草稿，列限制，不自动运行所有技能。

## 外部动作

- [ ] 当前任务是否只准备本地文件；
- [ ] 任何外部转换/审稿/提交前记录内容类别、用途、具体服务/接收方与目的地、允许发送范围和当前人类授权；
- [ ] 按 R2 human_approvals 核对 state、targets 版本/哈希、role、confirmed_at 及 source 的 human/actor_id/statement/reference/locator，人工核实权限；
- [ ] recorded_not_authenticated 不证明身份或有效同意，已连接工具、本地导出授权和科学 PASS 不等于外传许可；
- [ ] 目的地/范围/权限未知时不发送，采用已确认本地工具或本地草稿；变更内容/目的/目的地/范围后重新确认；
- [ ] 登录、上传、发送、公开与最终提交分别授权；真正提交前用户已看实际文件清单、版本和声明并最终确认；
- [ ] 回执记录预检时间、授权依据、实际发送字段/工件绑定、目的地、动作时间、执行状态、返回证据及限制；未执行如实记录，日志不复制患者正文或凭据。
