# 外部/跨模型审稿 — 第一轮模板

用途：按 SKILL.md“外部审阅预检”和“版本绑定与交接”执行用户请求的补充首轮审阅。
不强制运行，不构成独立专家评议或导出的前提。单模型多视角标注 single-model multi-lens review；
多个上下文/模型也需据实记录共享信息和限制，不宣称技术隔离保证意见独立。

发送前记录内容类别、用途、具体服务/目的地、允许发送的字段/文件范围和当前人类授权（R2 targets
版本/哈希、角色、时间、source 来源）；未知时不发送，改用已确认本地路径或只准备本地材料。
研究参与同意不等于患者发表同意，适用性不明须专业复核，不推定批准或豁免。

## 提示词骨架（供第一轮审稿使用）

```
请对以下材料进行医学论文模拟审阅，不冒充真实独立审稿人。
实际模型/运行方式：[填写]；材料范围与版本：[填写]；先前意见可见性：[如实填写]。
只依据可见材料提出意见，未核实内容标明限制。

请给出：
1. 总体评分（1-10分）
2. 按 critical / major / minor 三级分类的具体问题清单，每条问题需分配稳定 ID 并注明：
   - 出现位置（章节/段落）
   - 问题描述
   - 建议修改方向
3. 专项检查（若适用于本稿件的研究设计）：
   - "图作主语"检查：是否有大量段落以"图N展示了…""如表N所示，…"开头
   - 因果语言泄漏检查：观察性研究是否出现"优于/更安全/导致/改善预后/降低风险/提高生存"等
     暗示因果或优效的措辞
4. 给出 PASS / REVISE / REJECT 建议、实际覆盖范围、依据和限制；分数不替代关键问题判断。

[在此粘贴稿件正文]
```

## 使用说明
- 可减少先前意见输入以降低锚定影响，但新开会话不能保证意见独立性。
- 实际输出建议保存为 `paper/review/external-review-round1.md`，登记真实工件版本和哈希，供后续对照。
- 用 R2 检查字段记录 inputs、scope、execution_status、applicability、domain_result、report、checked_at；
  逐条读取 freshness，退出码 0 不等于科学 PASS，未运行时不生成模拟运行结果。
- 处理回执记录实际发送范围/工件绑定、接收方、时间、执行状态、返回证据和限制；未发送如实记录，避免敏感正文入日志。
- 若当前环境确有可用的因果语言或图表引用检查工具，可以先做预筛查，并把实际工具与结果记录为
  审稿参考；不要引用未部署的固定脚本。
