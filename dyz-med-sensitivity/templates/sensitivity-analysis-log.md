## 5. E-value（观察性研究，未测量混杂）

| 项目 | 数值/依据 |
|------|-----------|
| 原始效应尺度、方向及无效值 | 待核实；记录比较组与结局方向 |
| 原始点估计及CI | 待填写 |
| 效应尺度转换、适用条件及方法来源 | 原始RR可直接按风险比尺度处理；HR/OR等须核实转换方法及假设，不自动套RR公式 |
| 离无效值最近的CI界限（原始尺度） | 待填写；跨越或包含无效值时注明 |
| 计算使用的风险比尺度数值 | 记录转换后的点估计、界限及保护性效应的倒数处理 |
| 点估计E-value | 待计算/待核实 |
| 离无效值最近的CI界限E-value | 待计算/待核实 |
| 与已测混杂强度的比较 | 待填写；不使用通用切点 |

已确认RR尺度且CI不包含无效值1时：保护性RR=0.71、CI [0.54, 0.93]选0.93，按方法对保护性
效应取倒数后计算；风险增加RR=1.40、CI [1.10, 1.80]选1.10。已确认RR尺度的CI跨越或包含1时，
区间E-value为1，不能据此声称存在正向的抗未测量混杂稳健性。尺度、方向或转换条件未知时保留待核实，
不计算E-value。本表前述HR示例不能直接当作RR套用；表中待填值不代表已执行分析。
